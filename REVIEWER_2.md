# Ten objections to the report and talk

| Objection | What the evidence supports |
|---|---|
| The paper was never fully reproduced. | Correct. The assignment reproduces one released station prediction. The normalized discrepancy is shown on the reproduction slide and in the report. |
| The scalar wins by destroying amplitude. | The original scalar comparison makes that failure mode visible. SI-SDR, signed correlation and a local peak measure give complementary information. |
| The classical baseline was weak. | The revised filters see matched padding and use development-only candidate selection. The boundary-only control holds bandpass cutoffs fixed. |
| The nominal test was already examined. | V2 results were known. New choices are frozen on development events, but a new acquisition would give stronger confirmation. |
| Every neighboring channel is nearly the same example. | All splits use event IDs; summaries also aggregate by event. Time–distance bootstrap changes the dependence assumption explicitly. |
| The reference could reward matching the wrong signal. | It contains residual field noise. The alternate background and stack proxy test sensitivity but cannot create clean truth. |
| The magnitude finding could be a site effect. | Both extreme bins belong to Long Valley. Neither the plot nor the talk makes a cross-array causal claim. |
| Three source hours cannot establish noise robustness. | The larger matched comparison revises the previous three-target result. Generalization across days and campaigns remains open. |
| More weights lost because training was unfair. | The matched-update development results change the ordering. The deck qualifies its capacity claim by budget and cohort. |
| A visually strong mask or spectrum proves transfer. | The mask is one prespecified example. The spectra normalize power and identify which station traces are represented. The released model’s full training population is unknown. |
